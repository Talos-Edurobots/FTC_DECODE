Why the AI-Generated Control Award Pitch Is Weaker

Overview

Although the generated pitch sounds highly technical and impressive, it is less effective for FTC Control Award judging than a simpler presentation focused on engineering process and results.

---

Problem 1: Excessive Technical Jargon

The script uses many advanced terms:

- Inverse Distance Weighting (IDW)
- Normalized Feature Scaling
- Unit Scale Bias
- Debounced Sensor Fusion
- Low-Pass Filtered Velocity Derivatives

While these may be technically correct, they do not help judges understand the robot's capabilities within a 90-second presentation.

FTC judges are primarily interested in:

1. The problem that existed.
2. The engineering process used to solve it.
3. The resulting improvement.

Most of these terms belong in Q&A rather than the initial presentation.

---

Problem 2: Risk of Sounding AI-Written

Statements such as:

«"our code runs a normalized feature scaling algorithm before interpolating"»

or

«"debounced sensor fusion of three distance sensors"»

sound unnatural when spoken.

This can create doubt about whether students fully understand the concepts they are presenting.

Judges should leave the presentation thinking:

«"The team clearly engineered this system."»

not

«"The team memorized advanced terminology."»

---

Problem 3: Focuses on Methods Instead of Outcomes

The script spends significant time describing implementation details.

Examples:

- Feature scaling
- IDW interpolation
- Velocity derivatives

However, it spends very little time explaining:

- Increased scoring consistency
- Increased scoring area
- Reduced driver workload
- Increased reliability

The Control Award rewards the effectiveness of the control system, not the number of advanced algorithms mentioned.

---

Problem 4: Weak Engineering Narrative

A strong FTC presentation follows:

Problem → Investigation → Solution → Result

The AI-generated script often skips directly to:

Algorithm → Algorithm → Algorithm

This makes it harder for judges to understand why each design choice was made.

For example:

Instead of:

«"We use normalized feature scaling before interpolation."»

A stronger presentation would be:

«"We found that flywheel velocity affected shot trajectory, so we expanded our hood LUT to account for both distance and velocity."»

The second statement communicates the engineering reasoning.

---

Problem 5: Poor Time Allocation

A 90-second presentation is extremely limited.

Every sentence should answer one of these questions:

- What problem existed?
- What did we build?
- Why does it work better?

The AI-generated script allocates valuable time to details that judges can ask about later.

---

Problem 6: Weak Ending

The presentation ends with:

«"What questions do you have about our interpolation algorithms or simulation models?"»

This is unnecessary.

Judges already know they can ask questions.

A stronger ending summarizes impact:

«"These systems reduced driver workload and allowed consistent scoring from anywhere on the field."»

This leaves judges with a memorable takeaway.

---

What Should Be Kept

The following concepts are valuable and can remain in either the presentation or Q&A:

- Python simulation
- Virtual aiming model
- Dynamic lead compensation
- Sensorless shot detection
- Current-based turret homing

These features demonstrate genuine engineering effort.

---

What Should Be Moved to Q&A

The following concepts are excellent discussion topics but poor presentation topics:

- Inverse Distance Weighting interpolation
- Normalized feature scaling
- Unit scale bias
- Low-pass filtered velocity derivatives
- Detailed interpolation mathematics

These details become impressive when used to answer a judge's question.

---

Final Verdict

The AI-generated script attempts to maximize technical complexity.

The stronger FTC Control Award strategy is to maximize clarity:

- Explain the problem.
- Explain the solution.
- Explain the benefit.

Technical depth should be reserved for Q&A, where judges can explore the implementation details and verify the team's understanding.
