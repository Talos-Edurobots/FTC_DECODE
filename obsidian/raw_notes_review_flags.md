# Raw Notes Review Flags

These are not changes to memorize. They are small accuracy notes in case a judge asks.

- "Mostly autonomously" is safer than "fully autonomously" because the driver still chooses when to collect and shoot.
- If asked about transfer current monitoring, say it is used for monitoring/protection and debugging. The active automatic stop is mainly from the three sensors detecting full capacity.
- If asked about turret iterations, do not explain every version immediately. Say the short version first: "Each version fixed a specific aiming problem," then explain only if they ask.
