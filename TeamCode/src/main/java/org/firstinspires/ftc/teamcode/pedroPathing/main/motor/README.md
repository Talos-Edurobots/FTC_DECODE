Εδώ έχω βάλει όλα τα προγράμματα που αφορούν τους κινητήρες. 
Αυτή την στιγμή όλα τα subsystems χρησιμοποιούν αντικείμενα της MotorConfig κλάσης, η οποία περιέχει 
Position PIDF, Velocity PIDF, Trapezoidal Motion Profile + PID + Feedforward.

Επειδή η MotorConfig κλάση είναι πολύ μεγάλη και είναι δυσκολο για κάποιον να την χρησιμοποιήσει/καταλάβει/διαχειριστεί,
Σχεδιάζω παράλληλα ένα νέο σύστημα για να διαχειρίζεται τους κινητήρες, το οποίο θα είναι πιο απλό και πιο εύκολο στην χρήση.
Αυτό το σύτημα θα αποτελείται από πολλές κλάσεις, καθεμία από τις οποίες θα έχει μια συγκεκριμένη λειτουργία. Π.χ

PIDFFPositionController
PIDFFVelocityController
TrapezoidalMotionProfileController

Για να διασφαλίσω οτι αυτες οι νεες κλάσεις θα χρησιμοποιούνται με τις ίδιες εντολές, έχω φτιάξει 
ένα interface, το MotorController. Όταν γράφω σε καθεμία από τις παραπάνω κλάσεις:

public class PIDFFPositionController implements MotorController {
    // Κώδικας της κλάσης
}

Τότε μπορώ να χρησιμοποιήσω αντικείμενα της PIDFFPositionController κλάσης σε οποιαδήποτε εντολή, 
χωρίς να χρειάζεται να αλλάξω τίποτα στην εντολή, αρκεί η PIDFFPositionController κλάση να υλοποιεί 
όλες τις μεθόδους του MotorController interface.

Έτσι, μπορώ να αλλάξω τον τρόπο που ελέγχω τους κινητήρες μου, απλά αλλάζοντας την κλάση που χρησιμοποιώ, π.χ:

MotorController motorController = new PIDFFPositionController(...);
motorController.update(); // Καλεί την update μέθοδο της PIDFFPositionController κλάσης
motorController = new PIDFFVelocityController(...);
motorController.update(); // Καλεί την update μέθοδο της PIDFFVelocityController κλάσης, 
                          // χωρίς να χρειάζεται να έχω ξεχωριστό αντκείμενο για κάθε κλάση.

Αυτή την στιγμή οι παραπάνω κλάσεις ελέγχουν μόνο το μαθηματικό μέρος του ελέγχου των κινητήρων, 
δηλαδή υπολογίζουν την ισχύ που πρέπει να δοθεί στους κινητήρες για να επιτευχθεί ο στόχος.

Στο μέλλον, θα φτιάξω μια νέα κλάση, η οποία θα διαχειρίζεται τους ίδιους τους κινητήρες, 
δηλαδή θα καλεί τις μεθόδους των παραπάνω κλάσεων για να υπολογίσει την ισχύ.
